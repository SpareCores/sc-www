# Understand prices

[Navigator](https://sparecores.com/servers) and [Advisor](https://sparecores.com/advisor) provide controls for choosing which price data to use
and which currency to display. The displayed price depends on those choices.

## Choose a price category

In Navigator, the price selector offers:

- **Any price**
- **Ondemand prices**
- **Monthly prices**
- **Spot prices**

Advisor has a **Price allocation** option. Enable it to choose from the same
price categories.

Check the listing for the price values available for the servers you are
considering.

## Change the display currency

Use the currency selector to change the currency used for displayed prices.
For example, changing from USD to EUR changed the best-price values in the
Navigator listing.

Changing the display currency did not change benchmark efficiency figures
expressed in USD per hour during testing. Check the units shown with a value
before comparing prices or efficiency scores.

The available categories, currencies, and prices can change. Use the current
controls on [Navigator](https://sparecores.com/servers) or
[Advisor](https://sparecores.com/advisor) rather than relying on a fixed list
of currencies or prices.

For the related workflows, see [Find servers in Navigator](./navigator.md)
and [Get recommendations in Advisor](./advisor.md).
