# Understand Prices

The [Navigator](https://sparecores.com/servers) and the
[Advisor](https://sparecores.com/advisor) provide controls for choosing which
price data to use and which currency to display. The displayed price depends
on those choices.

## Choose a Price Category

The price selector above the [Navigator](https://sparecores.com/servers)
sets which prices count as a server's best price, which the **BEST PRICE**
column and the price-based scores use. It offers the following categories:

- **Any price**: the lowest price of the three categories below. This is the
  default.
- **Ondemand prices**: pay-as-you-go hourly prices, with no commitment.
- **Monthly prices**: on-demand prices per month.
- **Spot prices**: discounted prices for spare capacity, which the vendor can
  reclaim at short notice.

In the [Advisor](https://sparecores.com/advisor), select **Price allocation**
under **Limit search for matching:** to choose one of the same categories.
Without it, the Advisor uses any price.

## Change the Display Currency

Use the currency selector above the
[Navigator](https://sparecores.com/servers), in the
[Advisor](https://sparecores.com/advisor), or on a comparison page to show
prices in another currency. USD is the default.

Score-per-price values, such as $Core and **$ EFFICIENCY**, stay per USD per
hour whichever currency you choose. Check the unit shown with a value before
you compare prices or efficiency scores.
