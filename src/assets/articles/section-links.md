Our server and database pages are long. A server details page lists the
specifications, the prices, and a long series of benchmark charts, and a
comparison of a few servers is even longer. So when you wanted to show a
colleague the memory bandwidth of a server, you sent the page link and added
"scroll down to Memory Bandwidth".

Now you can link straight to the part you mean. In short:

- **Section links**: click the `#` next to a section heading, a chart title,
  or the FAQs to copy a link to that exact spot.
- **Share button**: server and database details pages have a new `Share`
  button next to `Compare`, which copies the link to the page.
- **Reliable landing**: a link to a section opens the page at that section,
  right below the site header, even when the charts load a bit later.

## Copy a Link to Any Section

Hover over a heading, and a `#` shows up next to it. Click it, and the link
to that section is on your clipboard, confirmed by a short "Link copied to
clipboard!" message. For example, the following link opens a Google Cloud
server's page at its Geekbench multi-core chart:
[/server/gcp/t2d-standard-1#geek_multi](/server/gcp/t2d-standard-1#geek_multi).

You can find these links on the following pages:

- server and database details pages: sections, benchmark charts, and FAQs
- server and database comparisons: every section of the comparison table,
  replacing the separate link buttons of the server comparison page
- [vendor pages](/vendors): the details, metadata, billing, and regions
  sections
- [benchmark workloads](/navigator/benchmark-workloads): each benchmark
  framework, such as `bogomips` or `bw_mem`
- blog articles, including this one: every heading
- the landing page and the [about](/about/spare-cores) and
  [partners](/about/partners) pages

## Share a Whole Page

The server and database listings, the [server prices](/server_prices) page,
and the [Advisor](/advisor) already had a share button in their page header.
Now the details pages have one too, and all of them use the same icon and the
same confirmation as the section links.

Note that the copied link is simply the page's URL, so a shared search keeps
its filters and a shared comparison keeps its servers and baseline. No
account is needed to share or to open the link. If you would rather keep a
page for yourself than send it, save it as a bookmark, as described in our
[Bookmark Your Searches and Comparisons](/article/registered-users) article.
